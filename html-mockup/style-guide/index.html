Typography

Fraunces, a warm, soft serif, for headings gives the site a human, community voice. Plus Jakarta Sans for body text is modern and highly legible at small sizes. Sizes scale fluidly between mobile and desktop with clamp(), so no text is ever smaller than 13px. Use italics in headlines sparingly to emphasise one idea.

Spacing & shape

A 4px base scale. Sections use fluid vertical padding (section-y: 64px mobile → 120px desktop). Cards use 24–40px inner padding. Corners: 6px (small), 14px (medium), 24px (cards), 32px (feature panels), full (buttons and chips).

Layout & grid

A 12-column grid with a 1280px maximum width. Side gutters scale from 20px on phones to 40px on desktop. Content collapses to a single column below 768px, two columns from 768px, and full asymmetric layouts (7/5, 5/7) from 1024px. The main navigation switches to a full-screen menu below 1024px, and the gold Donate button stays visible at every size.

Accessibility checklist

Designed and built to WCAG 2.2 Level AA guidance. A formal audit with assistive-technology users is recommended before launch.

  • Text contrast meets AA (see table above)
  • Visible gold focus ring on every interactive element
  • Skip-to-content link and semantic landmarks
  • One H1 per page with a logical heading order
  • Tap targets at least 44 × 44px
  • Descriptive alt text; decorative images hidden
  • Menus work by keyboard; Escape closes them
  • Mobile menu traps focus and restores it on close
  • Animations respect “reduce motion” settings
  • Scrolling text pauses on hover and focus
  • Form fields have labels, required markers and clear errors
  • External links announce that they open a new tab
  • Video loads only on request, with a text summary
  • Infographic data repeated as real text
