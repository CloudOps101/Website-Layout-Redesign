# PGCCDC website redesign

A new website for the **Prince George's County Community Development Corporation (PGCCDC)**. It replaces the current Squarespace site (princegeorges-countycdc.org) and is built with **Next.js 16, React 19 and Tailwind CSS 4**.

This is **Milestone 1: the interactive design mockup**. Every page is fully built, responsive and checked for accessibility, so the client reviews the real thing in a browser instead of a static picture.

Old Squarespace URLs (`/about-1`, `/projects-1`, etc.) redirect to the new pages. See `next.config.ts`.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

```bash
npm run build   # production build (all pages are static)
npm run lint
```

## HTML mockup

`html-mockup/` is a plain HTML/CSS/JS copy of the site for review (deployed on Netlify). It is generated from the Next.js pages, so it matches them exactly:

```bash
npm run build:html
```

See `html-mockup/README.md`.

## Editing content

- **Shared text** (organization details, programs, leadership, board, MID figures) lives in `src/content/site.ts`.
- **Page-specific text** lives in each page file under `src/app/**/page.tsx`.
- **Images** are optimised WebP files in `src/assets/img/`. `scripts/optimize-images.mjs` regenerates them. Stock photo credits are in `src/assets/img/CREDITS.md`.
- **Design tokens** (colours, type scale, spacing) are in `src/app/globals.css`. They are documented on `/style-guide` and in `DESIGN.md`.

## Contact form

Messages are delivered by [Web3Forms](https://web3forms.com) straight from the browser (no server code).

1. Create a free access key at web3forms.com using the inbox that should receive messages.
2. Locally: copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_WEB3FORMS_KEY`.
3. On Vercel: **Settings → Environment Variables** → add `NEXT_PUBLIC_WEB3FORMS_KEY`, then redeploy.
4. For the HTML mockup, `npm run build:html` picks the key up from the environment or `.env.local`.

Without a key the form still works: it opens the visitor's email app with the message filled in. A hidden "honeypot" field filters out spam bots.

## SEO and sharing

- `src/app/sitemap.ts` and `src/app/robots.ts` generate `/sitemap.xml` and `/robots.txt`.
- `src/content/site-url.ts` sets the public address used for canonical links, the sitemap and social images. On Vercel it follows the project's production domain automatically; the HTML mockup is built with `MOCKUP_URL` (default `https://pgccdc-mockup.netlify.app`).
- Icons (`favicon.ico`, `icon.png`, `apple-icon.png`) and the social-share image (`opengraph-image.jpg`) live in `src/app/` and are generated by `python scripts/build-brand-assets.py <fonts-dir>` (see the script for the font files).
- Organization details for search engines (schema.org JSON-LD) are in `src/app/layout.tsx`.

## Deploying

The site is built to deploy on **Vercel's free plan** under the client's own account:

1. Import this repository at vercel.com/new. The framework is detected automatically.
2. Add the domain `princegeorges-countycdc.org` under **Project → Domains**.
3. Update the DNS records shown by Vercel at the domain registrar (GoDaddy). Change only the `@` A record and the `www` CNAME; the MX, TXT and Microsoft 365 records run the organization's email and must stay as they are.
